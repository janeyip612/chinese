# Chinese Learning Maps

Self-study learning maps for Chinese classes, published with GitHub Pages.

```
index.html            course list
tnis/mandarin-2/      Mandarin II learning map
```

## Weekly update (Mandarin II)
Open `tnis/mandarin-2/data.js` on GitHub → pencil icon → change `CURRENT_WEEK` and `FOCUS` → Commit changes.
The site updates in about a minute.

## Files in each map
- `index.html` — the page layout
- `app.js` — how the map works (don't edit)
- `data.js` — the content: stations, words, sentence patterns, weekly focus

No student data is stored here. Student progress stays in each student's own browser.
